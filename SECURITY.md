# Security policy

`dependabot-map` is designed to run offline and read-only. It does not resolve
registry credentials, send telemetry, or contact GitHub. Please do not include
secrets in bug reports or fixtures.

For a security issue in the tool itself, open a private GitHub security
advisory on the repository when that feature is available. For non-sensitive
bugs, open a normal issue with a minimal reproducer and the report format
(`text`, `json`, or `sarif`).
